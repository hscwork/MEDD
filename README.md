The files contain the Choi Matrices and corresponding paremeters for Fig.1-7. Open the files with MATLAB.  
For each figure:
the variable "ChoiMatrixDDEraseFinal" contains the final Choi matrices with control and environment initializtion(s).
The variable "ChoiMatrixDDFinal" contains the final Choi matrices with control.
The variable "ChoiMatrixFreeEraseFinal" contains the final Choi matrices without control but with environment initializaiton(s).
The variable "ChoiMatrixFreeFinal" contains the final Choi matrices without control. 
The Corresponding final times are saved in the variable "finaltimes".
For the problem of quantum state control, the final states are calculated from the Choi matrices with Eq.(70).
